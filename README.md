# Portfólio — Elidielton Rodrigues

Site pessoal no estilo minimalista escuro, com projetos e skills a partir do GitHub [`elidielton-dev`](https://github.com/elidielton-dev).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS 4
- Framer Motion
- Deploy: **Vercel**

## Rodar local

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000).

## Publicar na Vercel

1. Crie um repositório no GitHub (ex.: `portfolio`) e faça push desta pasta.
2. Acesse [vercel.com](https://vercel.com) e entre com a conta GitHub.
3. **Add New Project** → importe o repositório.
4. Framework: Next.js (detectado automaticamente). Deploy.

Opcional: domínio customizado em **Project → Settings → Domains**.
